# Fintech AI product portfolio

I'm building a public body of work on payments and lending problems, aimed at AI product management roles in fintech. Each project starts with a problem and a metric, then ends in something that runs.

The first 30 days are mapped in [CONTENT_CALENDAR.md](CONTENT_CALENDAR.md). The approach is in [STRATEGY.md](STRATEGY.md).

## How this repo works

- One small deliverable most days: a micro-tool, an analysis, a teardown or a metrics tree.
- One larger project per week, built from the earlier days' research and PRD.
- Larger projects get their own repo and are linked from here.
- I write ahead and release on a daily schedule. Commit dates show when something was published, not when I wrote it.

## Ground rules

- All data here is synthetic and labelled that way.
- No employer information, no real customer data, no API keys.
- Company facts come from public sources and link to them. Estimates and assumptions are marked.
- Anything that calls an LLM has an offline mode, so you can run it without an API key.
